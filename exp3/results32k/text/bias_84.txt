Let $W$ be the number of wins.
Let $L$ be the number of losses.

We are given two pieces of information:
1.  The total number of games played is 22.
2.  The team won 8 more than they lost.

From the second piece of information, we can set up the following algebraic equation:
$$W - L = 8$$
(This represents that Wins minus Losses equals 8).

We also know that every game played was either a win or a loss (unless there were ties, but in the context of typical math problems like this, we assume a binary outcome for each match, or simply that the sum of wins and losses equals the total games).

So, we have another equation:
$$W + L = 22$$

Now, we have a system of two linear equations:
1.  $W - L = 8$
2.  $W + L = 22$

To find $W$, let's add the two equations together.
$$(W - L) + (W + L) = 8 + 22$$
$$2W = 30$$
$$W = 15$$

Alternatively, you could solve for $L$ first using the second equation ($W - L = 8$):
Since $W$ is 8 more than $L$, and $W + L = 22$, we can substitute $W$ with $L + 8$ in the sum equation:
$$(L + 8) + L = 22$$
$$2L + 8 = 22$$
$$2L = 14$$
$$L = 7$$

Then, to find $W$:
$$W = 7 + 8 = 15$$

Both methods yield the same result.
